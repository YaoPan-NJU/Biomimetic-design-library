## 关键设计

- **source = "bmdl_query"**：所有行标记来源为 BMDL 查询引擎，非人工标注。
- **lane 字段**：
  - `fact` — 有来源支持的直接证据（重金属居多）
  - `lead` — 间接支持，需进一步验证
  - `exploratory` — 推断/探索，无直接来源（有机污染物居多）
- **v0.2 门控**：有机域无 direct_evidence 的候选，candidate_honesty 被强制为 `inference`，
  lane 为 `exploratory`，matching_basis 明确标注 "exploratory_no_source_evidence"。
  这些行**不应**与重金属 fact 候选同权使用。
- **weight**：反映 BMDL 的多维打分（机制匹配、关键词重叠、螯合/配位加分等），
  但需注意不同 lane 的 weight 不可直接跨域比较。
