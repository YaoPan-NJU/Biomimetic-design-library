## 2. 设计问题与须超越的对照基准

A²/O 以固定的厌氧:缺氧:好氧体积比建成，按某一平均工况优化；进水偏离设计工况时性能退化（低 C/N → 反硝化碳源不足、出水 TN 升高；氨氮峰值 → 好氧能力不足；低温 → 硝化速率下降，需更大好氧容积 / 更长 SRT）。

**现有成熟做法（不构成仿生增量）：** 摆动区（swing zone，开关曝气以切换缺氧/好氧）、分段进水（step-feed）、可调内回流比与污泥回流比、DO/ORP 反馈控制、基于氨氮的曝气控制（ABAC）。

**因此仿生增量的判定门槛是：相对上述做法具备非显然性。** 仅将分区做成可切换并加以智能控制，不构成新意。

## 3. 生物原型与机制

### 3.1 主原型：微生物席 / 潮汐沉积物的氧化还原分层与昼夜锋面迁移
- **现象**：光合微生物席白天表层产氧，好氧–厌氧边界位于亚毫米深度；夜间呼吸主导时边界下移。好氧、微好氧、缺氧、厌氧菌群在毫米级梯度上共存。
- **关键特征**：功能性氧化还原分区是自组织的场（边界位置随驱动条件迁移），而非固定结构隔墙；深层厌氧 / 硫酸盐还原层稳定、基本不迁移，发生迁移的是近表层边界。
- **可迁移原理**：氧化还原分区可作为受控的场变量（以边界位置为状态量）加以管理，其控制自由度为产氧源（及电子供体 / 受体）相对局部需求的空间分布。
- **证据状态**：上述现象为成熟微生物生态学结论；其向工程反应器的映射为本库候选，具体可迁移参数待文献核实。

### 3.2 对照原型（结构 / 并行实现）：土壤团聚体 / 好氧颗粒污泥
- 土壤团聚体呈同心氧化还原微区（好氧外缘 + 缺氧 / 厌氧核心）；好氧颗粒污泥（如 Nereda 工艺）沿颗粒径向分层，在单一颗粒内同时实现硝化、反硝化与除磷，将空间序列折叠进径向结构。
- 意义：表明分区的"实现方式"不限于空间序列一种（详见 §11 后续待办，实现方式轴）。

### 3.3 配置空间背景（组织主线，非本切片交付物）
AO / A²O（=AA'O）/ AAOA / Bardenpho / UCT / MUCT 是同一生物脱氮除磷（BNR）配置空间内的离散点，差异仅在三个轴：实现方式（空间 / 时间 / 结构）× 序列拓扑（包含哪些氧化还原态、何种次序、几段）× 回流路由（硝化液 / 污泥回流的取放点、碳源投加点）。四条不变量界定可行域：①除磷需先有真厌氧接触；②硝化需稳定好氧环境与长 SRT；③反硝化需缺氧、硝酸盐与碳源；④硝酸盐不得进入厌氧区。本切片是该空间内"A²O ⇄ AAOA"一次配置变换的纵深演示。

### 3.4 氧化还原锋面的动力学描述（移动反应锋面框架）
反应器内的氧化还原锋面，本质是连续标量场（溶解氧 / 氧化还原电位场）中的移动界面，可纳入移动反应锋面（moving reaction front）/ 反应–扩散行波理论；沉积物与含水层的生物地球化学氧化还原锋面亦采用同一框架描述。该框架提供如下可量化描述量：

- **过渡带厚度（锋面陡度）**：决定相邻氧化还原区呈分立（薄过渡带）还是宽梯度共存（厚过渡带），对应 §5 的 `front_sharpness` 参数，并将配置空间"实现方式"轴（空间 ↔ 结构）由离散两类连接为连续区间。
- **锋面迁移速度与准稳态**：迁移速度趋零时锋面处于准稳态（产氧与局部耗氧平衡），对应额定稳态工况；大气准静止锋（梅雨期成因）可作直观类比。
- **锋面的形成与消解**：对应后置缺氧段的建立与撤除。
- **工况分类**：据迁移速度可将运行工况分为准稳态（稳定负荷）、快速迁移（负荷骤变 / 冲击）、缓慢迁移（负荷渐变）。

层次界定（避免将物理描述误作仿生原型）：生物原型（微生物席）提供"沿梯度的功能编排与鲁棒性"这一可仿生内容；锋面本身属物理—化学过程；移动反应锋面理论与大气锋面类比仅用作动力学描述与可解释性表述。气象现象不计入原型池。

## 4. 设计映射：A²O ⇄ AAOA 自适应后置缺氧

### 4.1 架构
```
进水 ──► [厌氧池：锚定（固定）]
              │ 除磷的关键前提：须可靠维持无氧、无硝酸盐；物理上无法按需快速生成，故固定保留
              ▼
        [缺氧 / 好氧连续段：可重配]
              │ 好氧核心（硝化菌世代时间长、空间锚定）维持
              │ 缺氧容量按负荷在空间上伸缩，并在前置 / 后置间切换
              ▼
        ┌─ 低负荷 / 常态：A²O 构型（以前置缺氧为主）
        └─ 低 C/N 或高 TN：动态建立后置缺氧段（+ 末端再曝气），形成类 AAOA 构型，深度脱除总氮
                                负荷回落 → 撤除后置缺氧段
回流：内回流（硝化液）与污泥回流路由随构型调整（隔离硝酸盐以保护厌氧区；向缺氧区供给硝酸盐）
```

### 4.2 控制变量（对应 AAOA、UCT/MUCT 中由人工设定的量，本设计使其随负荷自动调整）
- 缺氧容积占比；
- 缺氧前置 / 后置分配比例；
- 内回流 / 污泥回流路由与回流比；
- 后置缺氧段的碳源投加点与投加量（若设外加碳源）；
- **过渡带厚度（`front_sharpness`，由 bulk DO 设定值控制）**：薄过渡带 = 分立可移动边界（空间序列实现）；厚过渡带 = 缺氧微区就地共存（同步硝化反硝化 SND / 结构实现）。该参数将"空间实现 vs 结构实现"由离散两类变为连续可调，无需作离散取舍。

### 4.3 可调自由度与锚定约束的界定
1. **厌氧锚定**：制造厌氧条件的限速环节是硝酸盐反硝化（约 1–4 mgN/gVSS·h），将 5–10 mg/L 硝酸盐降至零需 0.5 至数小时，无法按需快速生成，故厌氧池固定保留。（说明：仅就溶解氧而言，充氧速率 OTR 与耗氧速率 OUR≈20–60 mg/L·h 处于同一量级，限速环节并非溶解氧。）
2. **好氧（硝化）锚定**：硝化菌生长缓慢、生物量在空间上无法快速迁移，故好氧核心位置相对固定。
3. **缺氧为灵活自由度**：缺氧条件 = 停止曝气 + 存在硝酸盐 + 存在碳源，可较快建立 / 撤除，前置与后置皆可。
4. **锋面迁移速度上限**：由最慢的相关生物过程（硝化活性的空间再分布）限定，而非溶解氧物理过程。锋面迁移速度若超过生物响应速度，仅引起溶解氧的空间波动而功能分区并未实际迁移，导致控制无效甚至锋面振荡。

## 6. 工程准入约束（须逐项填写）

- **改造可行性**：现有 A²/O 为固定隔墙，真正连续可重配反应器多需新建或拆除隔板；改造场景应退化为"加密摆动区 + 分段进水 + 动态回流"的近似方案，并如实标注退化代价。
- **控制系统成熟度**：依赖可靠的分布式传感与先进（含预测）控制，多数水厂不具备，故设计须能平稳退化（graceful degradation）至固定 A²O。
- **延伸缺氧段的无溶解氧混合**：缺氧区需温和混合以保持污泥悬浮，同时不引入溶解氧（与"缺氧区混合"问题相关联，见 `cross-domain-links.json`）。
- **稳定性**：响应时间常数 `τ` 失配将导致锋面振荡，需设置阻尼或最小驻留时间。

> 本节为排除性约束。前期评估中"鲨鱼皮沟槽减阻"案例即满足仿生溯源与非显然性，却因生物污染、低剪切等工程约束而被排除——本节即为防止此类方案进入。

## 7. 机器人的角色（团队自有支撑能力）

团队在研的可移动水下多指标在线监测机器人（pH、DO 等指标的时空分布）在本切片中承担：
1. **可观测性**：实测锋面位置，闭合控制回路，无需依赖点传感器外推；
2. **模型标定 / 证伪**：以真实三维氧化还原场标定 ASM / CFD 模型，补足旧库 verified=0 缺失的环节，使库参数首次可闭环验证；
3. **须注意**：(a) 机器人承担观测、曝气栅格承担执行，控制分辨率仍受执行端分段粒度限制；(b) 若巡测周期与锋面迁移时间（分钟级）相当，所得为时间平滑后的近似分布，闭环控制须计入采样滞后。
