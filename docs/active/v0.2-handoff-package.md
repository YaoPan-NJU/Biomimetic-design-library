## 2. Acceptance Boundary

### What v0.2 Delivers

- **Honest evidence labeling**: Every mechanism is tagged as from_source (PDF-extracted quote) or inference (DOI-based but no direct quote). No false precision.
- **ADRMATS integration**: 7 gold-set briefs with candidate_honesty classification (fact/lead/inference).
- **Boundary conditions**: Hard DO-NOT rules from source-verified evidence only.
- **Validator suite**: 15 validators covering causal chain completeness, gold-set usefulness, fact locator requirements, source tier consistency, and more.

### What v0.2 Does NOT Deliver

- **Ranked lists**: The library returns heuristic candidates, not ranked results.
- **Full evidence coverage**: 81% of mechanisms are inference-based (honest but unverified).
- **Performance guarantees**: All performance values are "leads" not "facts" unless explicitly marked from_source.
- **Expanded prototype set**: 36 root prototypes only; 60-80 expansion deferred to v1.0.

## 3. Known Limitations

1. **Evidence debt**: 412/510 mechanisms (81%) are source-backed inference without PDF-extracted quotes.
2. **Missing PDFs**: 18 DOIs cited by prototypes have no corresponding PDF in the library.
3. **OCR pending**: 3 scanned Chinese patents (CN113244898A, CN114570339A, CN113275374A) need OCR extraction.
4. **Prototype gaps**: 10 prototypes have no direct PDF support (background/exploratory only).
5. **Spider-silk uranium**: 3 mechanisms misclassified — decision pending on reclassify vs remove.
6. **Performance outliers**: Some extreme qmax values (e.g., 3429 mg/g plant-tannin, 2000 mg/g starch) need primary source verification.

## 5. ADRMATS Consumption Notes

### How to Use the Library

1. **Query**: Describe your adsorption target (pollutant, conditions, constraints).
2. **Retrieve**: ADRMATS returns heuristic candidates with honesty classification.
3. **Evaluate**: Check candidate_honesty (fact/lead/inference) and boundary conditions.
4. **Validate**: For high-stakes decisions, verify from_source mechanisms against cited PDFs.

### Brief Generation

- 7 gold-set test queries verified
- Briefs include: candidate list, mechanism binding, honesty ledger, boundary conditions
- All briefs pass gold-set usefulness, hard DO-NOT, and fact locator checks

### Honesty Ledger

Each candidate in a brief has:
- **Facts**: from_source mechanisms with PDF quotes
- **Leads**: Source-backed inference with DOI but no direct quote
- **Inferences**: LLM-generated reasoning (minimal, 8/510 mechanisms)
