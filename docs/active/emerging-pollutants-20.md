## 类别分布

- PFAS（全氟）：HFPO-DA / PFOA / PFBS / PFHxS（4）
- 有机氯农药/POPs：DDT / DDE / Dieldrin / Endosulfan / β-HCH（5）
- 氯代烃/溶剂：Chloroform / HCBD / SCCPs（3）
- 氯酚：2,6-DCP / PCP（2）
- 酚类EDC：BPA / Nonylphenol（2）
- 其它单类：PCB-209、BDE-209(PBDE)、TCDD(dioxin)、Octocrylene(UV)、Roxithromycin(抗生素)

## 诚实边界（必须遵守）

本库是仿生吸附原型库（贻贝/壳聚糖/硅藻等），对上述有机 POPs 基本无 source-backed 吸附证据。因此「加强证据」= ①建准 pollutant_profile（分子特征/电荷/pKa）②把这 21 个做成 relevance/honesty gold-set（验证它们被正确路由到 exploratory，绝不冒充 fact/lead）③仅在库内 643 篇 PDF 真有可迁移机制时才抽取证据，其余写进证据获取 backlog。不得凭空给有机物造仿生 qmax/机制。
