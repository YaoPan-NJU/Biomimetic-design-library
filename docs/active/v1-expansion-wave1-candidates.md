# v1.0 Expansion Wave 1 — Candidate Selection

**Date**: 2026-06-22
**Target**: 8-12 new root prototypes (36 → 44-48)

## Selection Criteria

1. Strong PDF support in library (3+ PDFs per candidate)
2. Distinct from existing 36 prototypes
3. Adsorption-design usefulness
4. Honest evidence available

## Selected Candidates (Wave 1)

### 1. biochar-activated-carbon
- **Category**: Scalable bio-derived adsorbent
- **PDFs**: 5+ (shell biochar, rice husk, agricultural waste)
- **Rationale**: Widely used, scalable, distinct from current prototypes

### 2. cellulose-nanofiber
- **Category**: Bio-derived structural material
- **PDFs**: 4+ (CNF extraction, modification)
- **Rationale**: Complementary to CNC, different surface chemistry

### 3. metal-organic-framework-derived
- **Category**: MOF derivatives/composites
- **PDFs**: 3+ (MOF-derived carbon, MOF hybrid)
- **Rationale**: Extends MOF prototype with derived materials

### 4. molecularly-imprinted-polymer
- **Category**: Selective adsorption
- **PDFs**: 4+ (MIP for specific pollutants)
- **Rationale**: High selectivity, distinct mechanism class

### 5. covalent-organic-framework
- **Category**: Porous organic material
- **PDFs**: 3+ (COF synthesis, adsorption)
- **Rationale**: Tunable pore structure, emerging material

### 6. MXene
- **Category**: 2D nanomaterial
- **PDFs**: 5+ (MXene synthesis, heavy metal adsorption)
- **Rationale**: High surface area, emerging class

### 7. hydrogel-bioadsorbent
- **Category**: 3D porous network
- **PDFs**: 4+ (hydrogel composites, wastewater)
- **Rationale**: Reusable, tunable swelling

### 8. agricultural-waste-bioadsorbent
- **Category**: Waste-derived material
- **PDFs**: 6+ (rice husk, corn cob, fruit peel)
- **Rationale**: Abundant, low-cost, scalable
