# v0.2 Gold-Set Evaluation

**Date**: 2026-06-21
**Purpose**: Result-level usefulness gate for v0.2 acceptance

## Evaluation Criteria

For each query:
1. **Scope-correct candidate precision**: Are candidates within the query domain?
2. **False-positive rate**: Are there misleading candidates?
3. **Fact truth/locator completeness**: Do facts have source + quote + locator?
4. **Mechanism alignment**: Does the displayed mechanism match the query?
5. **Hard DO-NOT behavior**: Are hard gates source-backed and blocking?

## Scoring Rubric

| Dimension | 0 | 1 | 2 |
|-----------|---|---|---|
| Scope precision | Wrong domain | Partially correct | Fully correct |
| False positives | Misleading candidates | Minor issues | None |
| Fact truth | Fabricated claims | Incomplete | Source+quote+locator |
| Mechanism alignment | Unrelated mechanism | Partially aligned | Query-matched |
| DO-NOT behavior | Ignored/inferred | Display only | Source-backed blocking |
