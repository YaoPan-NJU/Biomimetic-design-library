## 0. 深度声明（必读）

本表为**分诊深度（triage depth）**，刻意浅：

- 每条切片仅一页式画像，字段统一，用于**比较与排期**，**不是库内容、未经核实**；
- 非显然主张、参数、原型映射均为**候选**，须经文献核实 + 仿真/实测后方可升级；
- 仅 A²/O（S1）已达 spec + 实施计划深度，作为模式锚点；其余为待选项。

**目的**：看清版图、挑出值得投入的切片，避免在模式验证前批量产出未核实内容（即防止旧库 verified=0 问题在更大面积重演）。

---

## 1. 切片的定义

**切片 = 工艺 × 标志性问题 × 候选生物原型**，纵向走完"生物 → 反应器/系统尺度启示 → 可进工具验证的非显然参数 → 工程约束 → 验证"。

一个工艺含多个问题，故一个工艺可派生多条切片；一条切片**天然跨多个领域**（A²/O 切片即跨 shock-resistance + microbial-community/biofilm + mass-transfer/fluid-mechanics）。跨域发现由两阶段路由 + `cross-domain-links.json` 承担——候选切片同时也是路由机制的检验用例。

---

## 2. 配置空间视角下的活性污泥工艺族

A²/O、OD、CASS、Bardenpho 并非并列同类，而是同一 BNR 配置空间在不同轴上的采样点：

| 工艺 | 在配置空间中的位置 | 实现方式轴 | 与 A²/O 切片的关系 |
|------|--------------------|------------|---------------------|
| A²/O ⇄ AAOA | 前置缺氧 + 动态后置缺氧 | **空间** | 锚点切片（S1） |
| Bardenpho | 多级、含后置缺氧（深度脱氮） | 空间（序列更长） | **A²/O 配置轨迹的静态终点 → 并入 S1，不单列** |
| OD（氧化沟） | 环流式连续反应器 | **环流/流场** | 不同问题族（流场），独立切片 S2 |
| CASS（SBR 族） | 时间相位实现 | **时间** | 同原型（微生物席）不同实现轴，补 R3 时间支，S3 |
| 好氧颗粒 / 生物膜 | 径向分层 / 载体附着 | **结构** | 结构实现，S6 / S7 |

**结构性结论**：把 S1（空间）+ S3（时间）+ S6/S7（结构）做出来，即同时验证了评估 R3 挂起的"实现方式轴"——三种实现何者最承载自适应、最易改造。Bardenpho 不单列。

## 3. 候选切片登记表

> 评级口径：以"能否胜过最佳现有实践"为准（须超越 ABAC / 导流墙 / 商业载体优化等，而非仅胜朴素基线）。

### S1 · A²/O 进水波动分区自适应 ★已达 spec 深度
- **标志性问题**：进水波动下分区刚性 → 出水 TN/TP 波动
- **候选原型**：微生物席 / 潮汐沉积物（氧化还原分层 + 锋面迁移）
- **非显然主张**：缺氧容量运行时空间重配（A²/O⇄AAOA），锋面迁移速度受最慢生物过程限定
- **主验证工具**：ASM 动态（GPS-X/BioWin）+ 机器人标定
- **涉及领域**：shock-resistance(主)、microbial-community/biofilm、mass-transfer/fluid-mechanics
- **实现方式轴**：空间
- **诚实评级**：核心增量明确，待仿真证实（详见专属 spec/实施计划）
- **工作量**：高（已有完整 WBS）

### S2 · 氧化沟（OD）弯道死区·流速分层·能耗
- **标志性问题**：180° 弯道死区与短流、底部流速不足致污泥沉积、表曝能耗高
- **候选原型**：① 蜿蜒河流弯道二次流（Dean 涡）→ 弯道几何诱导可控二次流冲刷底部、均化断面；② 座头鲸鳍前缘结节 → 转刷/转碟叶片，减涡脱落、提升充氧
- **非显然主张**：以二次流强度（helicity/Dean 数）而非平均流速为设计目标量；结节化叶片前缘
- **主验证工具**：**CFD（Fluent/OpenFOAM）** + 实验
- **涉及领域**：fluid-mechanics(主)、mass-transfer
- **实现方式轴**：环流/流场
- **诚实评级**：中高——二次流防淤相对"倒圆角 + 导流墙"非显然；须证明胜过现有导流墙基线
- **价值**：验证契约里 **CFD 这一极**（S1 用 ASM），证明模式跨参数-工具谱通用
- **工作量**：中

### S3 · CASS（SBR 族）周期内氧化还原调度·盛宴-饥饿
- **标志性问题**：固定周期相位跟不上负荷波动；盛宴-饥饿节律未优化
- **候选原型**：微生物席**昼夜节律**（时间维迁移）+ 潮汐滩涂周期性氧化还原循环
- **非显然主张**：把"分区"实现为周期内的时间调度，锋面在时间轴上迁移；与 S1 空间实现互为对偶
- **主验证工具**：ASM 动态（批次模式）
- **涉及领域**：shock-resistance(主)、microbial-community
- **实现方式轴**：时间
- **诚实评级**：中——CASS 本就时间自适应，增量在"周期内锋面调度"；**复用 S1 原型，边际成本低**
- **价值**：补 R3 时间支；直接检验"同原型、不同实现轴"
- **工作量**：中低（复用 S1 原型与模型框架）

### S4 · Bardenpho 深度脱氮 → 并入 S1，不单列
- **理由**：Bardenpho 是 A²/O⇄AAOA 配置轨迹的静态终点，单列高度重复。作为 S1 的"拓扑终点"情景纳入即可。

### S5 · 二沉池（SST）异重流·短流·出水 SS
- **标志性问题**：进水分布不均、温差/浓度异重流、短流致出水悬浮物升高
- **候选原型**：河口盐楔/异重流的自然分层与导流（自然界对密度流的"管理"而非"消除"）
- **非显然主张**：顺应而非对抗异重流的进水分配与导流结构设计
- **主验证工具**：CFD + 示踪 RTD
- **涉及领域**：solid-liquid-separation(主)、fluid-mechanics
- **诚实评级**：中高——异重流是公认难题，自然界有密度流管理先例；须胜过现有中心导流筒设计
- **工作量**：中

### S6 · 厌氧反应器（UASB/IC）颗粒污泥·三相分离·传质
- **标志性问题**：颗粒污泥培养困难、三相分离效果差、上升流传质受限
- **候选原型**：瘤胃微生物固定化 / 颗粒自组装（结构实现：径向功能分层）
- **非显然主张**：以颗粒径向氧化还原/营养分层为设计目标的造粒与三相分离协同
- **主验证工具**：CFD（多相）+ 厌氧 ASM（ADM1）
- **涉及领域**：microbial-community、mass-transfer、metabolic-pathways
- **实现方式轴**：结构
- **诚实评级**：中——造粒机理复杂、证据分散
- **工作量**：中高

### S7 · MBBR/BAF 载体几何·挂膜·流化均匀
- **标志性问题**：挂膜困难、生物膜过厚脱落、填料流化不均/堵塞
- **候选原型**：多孔生物膜基质（树皮韧皮部 / 珊瑚骨骼孔隙的梯度孔结构）
- **非显然主张**：梯度孔隙载体 → 调控生物膜厚度分布与传质
- **主验证工具**：CFD（载体局部水力）+ 生物膜模型
- **涉及领域**：biofilm(主)、mass-transfer
- **实现方式轴**：结构（组件尺度为主）
- **诚实评级**：中——载体几何已被商业产品高度优化，增量门槛高
- **价值**：以**组件尺度**为主，检验尺度轴（S1 为系统尺度）
- **工作量**：中

### S8 · 曝气充氧效率（跨工艺通用）
- **标志性问题**：鼓泡曝气氧转移效率低、能耗占全厂最大
- **候选原型**：鱼鳃 / 鸟肺单向逆流气体交换
- **非显然主张**：逆流换气相对鼓泡曝气是根本不同的传质机制
- **主验证工具**：CFD + 传质实验
- **涉及领域**：mass-transfer(主)
- **诚实评级**：中偏低——机制吸引力强，但工程实现（膜污染、低压损单向流构造）是已知杀手，须先过工程约束筛
- **工作量**：高（实现难）

## 4. 优先级建议

| 层级 | 切片 | 理由 |
|------|------|------|
| 锚点 | S1（A²/O） | 已 spec，先用实施计划跑出 Go/No-Go |
| 第一梯队 | **S2（OD）+ S3（CASS）** | S2 验证 **CFD 极**（S1 是 ASM 极），证明契约跨工具通用；S3 复用 S1 原型、补时间支、成本低。两者合起来以低成本拿到"跨工具 + 跨实现轴"的证据 |
| 第二梯队 | S5（二沉池）、S6（UASB） | 拓展到分离族与厌氧族，但各自机理复杂 |
| 第三梯队 | S7（MBBR 组件尺度）、S8（曝气） | S7 测尺度轴；S8 机制诱人但工程约束严，先过筛 |
| 并入 | S4（Bardenpho）→ 并入 S1 | 避免重复 |

**依赖**：所有切片应等 S1 的 Go/No-Go 出结果后再投入——若 S1 证伪了"反应器/系统模式"，整批需重新框定。S2/S3 可在 S1 进入仿真阶段后并行启动（不同工具链、不同人）。

## 5. 这张表暴露的结构性发现

1. **配置空间是有效的去重器**：它直接判出 Bardenpho 应并入 S1，避免了一条重复切片。这支持把"配置空间导航"升格为反应器/系统场景的组织主线（评估开放问题 1）。
2. **切片可按"验证工具"与"实现方式"两轴布点**，用最少的切片覆盖最大的证据面：S1(ASM/空间) + S2(CFD/环流) + S3(ASM/时间) + S7(CFD/结构·组件) 已覆盖两轴大部分格子。
3. **诚实评级把"机制诱人但工程不可行"的候选（S8）显式标出**，复用了 spec §6 的排除性约束纪律。
4. **跨域是常态而非例外**：8 条切片每条都跨 ≥2 领域，印证两阶段路由的必要性，也意味着 `cross-domain-links.json` 需尽早随切片同步建设。
