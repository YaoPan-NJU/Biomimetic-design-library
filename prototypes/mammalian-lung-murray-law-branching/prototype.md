# 哺乳动物肺支气管树 Murray 律分级传质网络（Mammalian Lung Bronchial Tree Murray-Law Hierarchical Mass-Transfer Network）

## 1. 生物原型简介

**问题定义**：在 ng/L 级超低目标浓度下，吸附床层面临驱动力极低、传质通量难以维持、目标物难以高效送达吸附位点的工程难题。长程低驱动力输运是自然界反复出现的问题，进化已在动物器官中给出几何解。

**生物策略**：哺乳动物肺以进化优化的分级传质网络给出自然解：气道平均约 23 级对称二叉分支（Weibel & Gomez 1962 摘要），分支半径按 Murray 律（平均流量正比于半径立方）逐级递减（Murray 1926 最小功原理；肺动脉 Murray 律研究 2025 复述），终止于约 3 亿肺泡末端（Weibel & Gomez 1962），形成约 40-80 m² 的巨大交换面积。LaBarbera 1990 指出，体内流体输运系统呈两种几何之一——单管中断于平面传质区，或分支管网连接广布传质区；动物借壁面剪应力信号反复进化出逼近全局最优、最小化构造-维持代价的复杂分支层级。该几何在极低驱动力下维持高通量气体交换。

## 2. 吸附机制详解

### 机制1：Murray 律立方递减分级传质网络（最小功原理）

**描述**：哺乳动物肺支气管树以对称二叉分支将主干逐级细分为约 3 亿末端交换单元，分支半径按 Murray 律（平均流量正比于半径立方）递减；该几何源自 Murray 1926 最小功原理——在泵送功耗与代谢/血液体积代价间取最小总代价，使分支管网逼近全局最优、逐级维持恒定单位输运代价，是长程低驱动力输运的几何最优模板
**关键官能团**：['分级分支孔道几何（对称二叉、半径立方递减）', '广布末端传质/交换面']
**来源**：DOI 10.1073/pnas.12.3.207

### 机制2：人肺约 23 级对称二叉分支至约 3 亿肺泡末端的形态测量几何

**描述**：Weibel 人肺形态测量（1962/1963）确立：气道平均约 23 级对称二叉分支，终止于约 3 亿肺泡（配约 1400 万肺泡管、约 2800 亿毛细血管段），逐级气道与血管直径遵循'最优'尺寸，交换面积约 40-80 m²；该形态测量是 Murray 律分支几何在哺乳动物肺的器官级实例
**关键官能团**：['对称二叉分级孔道（约 23 级）', '约 3 亿肺泡末端高交换面积单元']
**来源**：DOI 10.1126/science.137.3530.577

## 3. 结构特征与结构-功能关系

必须保留：① 对称二叉分支的分级孔道（主干→分支→末端）；② 半径按 Murray 律立方递减以维持逐级恒定单位输运代价；③ 大量末端高交换/吸附面积单元。可灵活调整：级数、各级绝对孔径、末端域负载的吸附剂与识别基团、单体材质与制造工艺。

## 5. 适用场景

**约束条件**：
- 气-液界面与液相吸附的相态差异: 肺为气-液界面气体交换器官，其分级几何服务于气体扩散；转译为液相吸附床时，传质介质、驱动力与界面性质均改变 None
- 动态通气与静态床层的动力差异: 肺靠呼吸主动通气维持气流；吸附床为静态/被动结构，低驱动力须由外加流速/压差提供，分支几何本身不提供动力 None
- 立方律半径递减的实体化制造难度: 在合成单体中精确实现约 23 级、半径立方正比流量的逐级径缩分支孔道，制造与表征难度高 None
- Murray 律最优依赖代价权衡假设: 立方律是泵送功耗与代谢耗散代价平衡下的最小功最优，假设改变时分支几何偏离立方律 None
- 形态测量的种属特异性: 约 23 级二叉分支与约 3 亿肺泡基于 5 例 8-74 岁正常人肺，为人肺特异形态测量 None
