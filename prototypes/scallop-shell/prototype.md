# 扇贝壳（Scallop Shell）

## 1. 生物原型简介

**问题定义**：农田土壤重金属(Cd, Pb等)污染导致作物富集，威胁食品安全；天然贝壳废弃物堆积造成资源浪费和环境污染。需要低成本、环境友好的材料来原位钝化重金属。

**生物策略**：贝壳是自然界经生物矿化形成的碳酸钙(CaCO3)生物陶瓷复合材料，具有95%的无机矿物成分和5%的有机质(贝壳素)。其独特的微层结构(棱柱层和珍珠层)和2-10 µm微孔网络提供了巨大的比表面积和离子交换位点。贝壳中的Ca2+、Mg2+可与重金属发生离子交换，其碱性(CaCO3或煅烧后的CaO)可提升土壤pH，促使重金属生成碳酸盐/氢氧化物沉淀。

## 3. 结构特征与结构-功能关系

必须保留：贝壳的微孔结构(物理吸附)、碳酸钙晶格(离子交换/沉淀)、天然碱性(pH提升)。可灵活调整：煅烧温度(400-1000℃)、球磨细化程度、与功能材料复配比例。
