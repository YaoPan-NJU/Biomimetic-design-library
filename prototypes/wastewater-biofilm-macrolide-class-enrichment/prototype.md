# 成熟污水生物膜大环内酯类别富集界面（Mature Wastewater Biofilm Macrolide-Class Enrichment Interface）

## 1. 生物原型简介

**问题定义**：痕量大环内酯抗生素(克拉霉素/红霉素/罗红霉素)在市政二级出水中需选择性去除；如何在真实水基质下对‘一类’两亲大分子形成类别级富集，而非依赖单一分子印迹。

**生物策略**：Torresi 2017(Water Res, PMID 28686941)在痕量、真实二级出水、失活生物膜条件下研究 23 种微污染物在不同厚度生物膜中的扩散与吸附：较厚成熟生物膜对克拉霉素/红霉素/罗红霉素表现出接近的高分配，而若干无关阳离子药物明显较低，呈‘大环内酯类别级富集’；失活膜排除了生物降解为唯一解释。Burzio 2024 亦观察到正电微污染物(含克拉霉素/红霉素)向颗粒污泥/泡沫分配。机制解释：成熟生物膜水化多孔界面(EPS/磷脂)以重复出现的浅层弱阴离子区+相邻低极性区，对带正电区+大低极性骨架的两亲大环内酯提供类别级分配环境。

## 2. 吸附机制详解

### 机制1：成熟污水生物膜对大环内酯类的类别级分配富集

**描述**：Torresi 2017 在痕量、真实二级出水、失活生物膜条件下研究多种微污染物在不同厚度生物膜中的扩散与吸附；较厚的成熟生物膜对克拉霉素/红霉素/罗红霉素等大环内酯表现出接近的高分配，而对若干无关阳离子药物明显较低——呈现‘大环内酯类别级富集’现象（失活生物膜已排除生物降解为唯一解释）
**关键官能团**：['水化弱阴离子浅层界面', '相邻低极性(疏水)区']
**来源**：DOI 10.1016/j.watres.2017.06.027

## 3. 结构特征与结构-功能关系

必须保留：① 水化弱阴离子浅层位点；② 紧邻的低极性(疏水)区；③ 该‘阴离子—低极性相邻界面’在多孔结构中重复出现且水可接近。可灵活调整：孔壁覆盖度、界面密度。须警惕：类别富集是事实，‘由某一 EPS/磷脂界面造成’待验证；薄膜无同样优势。
