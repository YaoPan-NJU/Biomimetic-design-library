# ArsR 砷感应蛋白三硫醇(AsS3)诱导折叠捕获（ArsR Arsenic-Sensing Trithiol (AsS3) Disorder-to-Order Capture）

## 1. 生物原型简介

**问题定义**：As(III)(亚砷酸)在中性 pH 多为中性 H3AsO3，常规离子交换/含氧阴离子识别难以选择性捕获；须在磷酸/硫酸等背景中特异读取 As(III)。

**生物策略**：细菌 ArsR/SmtB 家族 As(III) 感应抑制蛋白以 3 个半胱氨酸硫醇对 As(III) 形成三角锥三配位(AsS3)：Shi 1996(JBC 271:9291)证明三半胱氨酸缺一即显著削弱结合；Prabaharan 2019 解析三配位硫位点结构；Zhu 2023(JACS，DOI 10.1021/jacs.3c11665)表明 As(III) 选择性诱导 AfArsR 无序到有序转变。软-软匹配(As(III)-3S)+三角锥几何提供对亚砷酸的高选择性，并把识别与构象折叠耦合。

## 2. 吸附机制详解

### 机制1：As(III) 三半胱氨酸三配位(AsS3)与无序到有序折叠捕获

**描述**：ArsR/SmtB 家族 As(III) 感应抑制蛋白以 3 个半胱氨酸的硫醇对亚砷酸 As(III) 形成三角锥三配位(AsS3)；AfArsR 中 As(III) 结合诱导一段无序区折叠为有序结构(disorder-to-order)，实现对 As(III)/Sb(III) 的选择性感应(Shi 1996；Prabaharan 2019；Zhu 2023 JACS)
**关键官能团**：['三半胱氨酸硫醇(AsS3 三配位)', 'As(III) 诱导折叠肽段']
**来源**：DOI 10.1021/jacs.3c11665

## 3. 结构特征与结构-功能关系

必须保留：① 3 个软硫配体(半胱氨酸)三角锥几何；② 软-软匹配锚定 As(III)；③（可选）配位诱导折叠作信号/再生响应。须警惕：只对 As(III) 有效(As(V) 走硬阴离子路线)；硫醇易氧化；缺一硫配体即失效。
