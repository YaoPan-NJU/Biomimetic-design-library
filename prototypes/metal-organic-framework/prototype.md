# 金属有机框架（Metal Organic Framework）

## 1. 生物原型简介

**问题定义**：自然界中天然多糖聚合物需在复杂水环境中保持结构稳定并实现多靶点分子识别；对应水处理中，传统合成吸附剂常面临结合位点单一、水相溶胀失稳、固液分离困难及再生性差等挑战。

**生物策略**：进化策略：利用天然碱性多糖（壳聚糖）分子链上丰富的极性基团构建非共价与共价协同作用网络。关键机制：通过-NH₂和-OH基团实现离子交换、络合、配位/螯合、静电吸引、酸碱反应、氢键及疏水相互作用七种机制的灵活切换与协同。成功案例：壳聚糖基复合材料（如磁性水凝胶、ZIF-8@纳米纤维、交联凝胶珠）对刚果红、亚甲基蓝、孔雀石绿等染料实现>1000 mg/g的超高吸附容量。

## 3. 结构特征与结构-功能关系

必须保留特征：-NH₂与-OH核心功能基团、七重吸附机制协同作用、磁性快速分离模块；可灵活调整特征：交联密度与交联剂类型（调控溶胀与容量平衡）、宏观形态（水凝胶/纳米纤维/海绵/微球）、复合填料种类（GO、MOFs、黏土等以增强机械强度与比表面积）。

## 5. 适用场景

**约束条件**：
- 酸性条件吸附优势原理 Why acidic pH favors Cr(VI) adsorption: 酸性条件下吸附剂表面易被H⁺质子化带正电，对带负电的HCrO₄⁻或Cr₂O₇²⁻亲和性高；碱性条件下OH⁻与CrO₄²⁻竞争吸附 None
- ZIF-67/BC/CH气凝胶对Cr(VI)吸附及再生: pH=6时最大吸附; 5次循环后保持72% None
- nFe₃O₄@MIL-88A(Fe)/APTMS对Cr(VI)吸附及再生: 5次循环后去除率仅下降3% %
- PVDF/PAN/壳聚糖/UiO-66-NH₂纳米纤维膜长期稳定性: 18小时超长去除时间; 稳定膜通量 h
- BUT-39对Cr₂O₇²⁻吸附性能及再生问题: 215 mg·g⁻¹
- MOF材料水稳定性提升策略: 高价金属-含氧配体(Zr羧酸盐/Zr酚盐/Cr羧酸盐/Fe羧酸盐); pKa大的唑类配体(Zn咪唑盐/Ni吡唑盐); 提升疏水性 None
- Cu-BTC对亚甲基蓝的吸附条件与再生: pH=7时最大吸附容量 None
- pH对BPA吸附的影响 pH effect on BPA adsorption: pH 2-8范围内对去除效率影响较小；pH 9-11时BPA吸附效率下降(BPA在pH>8开始去质子化，阴离子形态与带负电吸附剂表面产生静电排斥) None
- 温度对BPA吸附的影响 Temperature effect on BPA adsorption: BPA吸附通常是放热过程(温度升高吸附容量下降)；但某些材料因表面化学或孔结构变化在高温下吸附容量反而增加 None
