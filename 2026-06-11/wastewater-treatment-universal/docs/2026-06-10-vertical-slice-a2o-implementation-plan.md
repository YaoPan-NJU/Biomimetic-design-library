## 1. 目标与可证伪命题

**工程命题（须被证伪或证实）：**
> 在标准动态进水情景下，A²O 运行时自适应重配缺氧容量（A²O ⇄ AAOA），相对**最佳现有实践**（含 ABAC 曝气控制、固定摆动区、可调回流），能在**等于或更低的曝气能耗**下，将出水 TN（及 TP）的波动（方差 / 超标历时）降低不小于预登记阈值；且该增益依赖于"锋面迁移速度受最慢生物过程限定"这一约束。

若命题成立 → 该场景模式可复制，进入第 5 阶段沉淀为库条目并横向扩展；若不成立 → 记录边界，重新界定场景。**阈值须在仿真前预登记**（见 §4.4），以保证判定可证伪。

## 3. 仿真技术设定

### 3.1 平台选择

| 选项 | 性质 | 适用 |
|------|------|------|
| GPS-X / BioWin / SUMO / WEST | 商业，内置 ASM2d、动态进水、控制模块 | 团队若已有授权，首选（最省搭建成本） |
| QSDsan / 自建 ASM2d（Python） | 开源、可复现、便于嵌入自定义控制律与机器人数据 | 无授权或需深度定制控制器时 |

**模型选型：ASM2d**（含聚磷菌 PAO、反硝化、硝化、化学除磷），理由：A²O 须同时模拟脱氮与生物除磷，ASM1/ASM3 不含 P，ASM2d 为 EBPR + 脱氮的事实标准。

### 3.2 反应器空间离散
生化段离散为 **N = 12–20 个串联全混釜（CSTR-in-series）**，用以表征沿程氧化还原梯度与锋面位置。每釜可控元素：
- 曝气：`kLa_i` 或 DO 设定值（含"关闭"状态）；
- 碳源：可选投加点与投加量；
- 回流：内回流（硝化液）与污泥回流的取出釜、返回釜可切换。

"锋面位置 `x_front`" = 曝气与非曝气区的边界釜序号；"重配" = 改变受曝气釜集合 + 回流取放点。厌氧池为前置独立单元（固定，不参与重配）。

### 3.3 基线工艺参数（占位，待按参照厂设定）

| 项 | 取值（占位） |
|----|-------------|
| 设计流量 Q | 10,000 m³/d（参数化） |
| 总水力停留时间 HRT | 8–10 h |
| 厌氧:缺氧:好氧（基线体积比） | ≈ 12.5% : 25% : 62.5% |
| 内回流比 IR / 污泥回流比 RAS | 100–400% / 50–100% |
| MLSS / SRT | 3,000–4,000 mg/L / 10–15 d |
| 温度区间 | 12–22 ℃ |
| 进水 COD / TN / TP | ≈ 400 / 40 / 6 mg·L⁻¹（含组分划分） |

## 4. ASM 验证情景的具体设定

### 4.1 实验臂

| 臂 | 描述 | 控制 |
|----|------|------|
| Arm A | 朴素固定 A²O | 好氧区固定 DO≈2 mg/L，固定 IR/RAS，固定池容 |
| **Arm A′（主对照）** | 最佳现有实践 | ABAC（按氨氮调曝气）+ 摆动区开关 + 可调 IR/RAS |
| **Arm B（受验设计）** | A²O ⇄ AAOA 自适应 | 缺氧重配控制律 + 物理约束（§2.3）+ 可选 `front_sharpness` 扫描 |

> 关键：增益须以 **Arm B 优于 Arm A′** 为准（须超越最佳实践，而非仅超越朴素基线），否则不认定仿生增量（对应 spec §2、§6）。

### 4.2 进水/扰动情景

| 编号 | 情景 | 设定 | 考察点 |
|------|------|------|--------|
| S0 | 稳态 | 设计平均负荷，模型预热与标定 | 基线出水 |
| S1 | 旱季昼夜动态 | 采用 BSM 旱季动态进水（流量 + COD + N 24 h 周期）；为 ASM2d 补充 P 组分 | 日内波动适应 |
| S2 | 雨季稀释事件 | 采用 BSM 暴雨/暴雨型进水文件（高流量、低浓度） | 高流量低 C/N 适应 |
| S3 | 低 C/N 冲击 | 在 S1 基础上阶跃降低进水 COD（或升 N）持续设定时长 | 反硝化碳源不足应对 |
| S4 | 低温 | 温度降至 12 ℃，硝化速率下降 | 好氧容量再分配 |

> BSM（Benchmark Simulation Model）动态进水提供可复现、被广泛引用的流量/COD/N 时间序列；其本体基于 ASM1（不含 P），故 P 组分按 ASM2d 进水组分划分另行补充。

### 4.3 控制律初始设定（供仿真起步，后续标定）

- **触发判据**：估计 C/N < 阈值 或 出水 TN 预测 > 阈值 → 建立后置缺氧；负荷恢复 → 撤除。
- **`x_front` 设定律**：起步用基于稳态扫描的规则/查表控制器（后续可升级为模型预测控制 MPC）。
- **`v_front,max`**：限制曝气边界釜的切换速率（如每 `τ_min` 不超过 1 个釜）；`τ_min` 与硝化活性响应挂钩，取初值并做敏感性分析。
- **`front_sharpness`**：受曝气区 bulk DO 设定值——高 DO（≈2）= 薄过渡带/分立区；低 DO（≈0.5）= 厚过渡带/SND 共存；在 3.2 中扫描。

### 4.4 指标与预登记判定阈值

| 类别 | 指标 | 判定阈值（仿真前冻结，示意） |
|------|------|------------------------------|
| 主（出水稳定性） | 出水 TN 方差 / 95 分位 / 超标历时（S1–S4 综合） | Arm B 相对 Arm A′ 降低 ≥ 20%（超标历时） |
| 主（除磷） | 出水 TP 方差 / 超标历时 | 不劣于 Arm A′ |
| 约束（能耗） | 曝气能耗（kWh/d，由 kLa→风量→功率换算） | ≤ Arm A′ |
| 次（韧性） | 冲击后恢复时间（S3） | 短于 Arm A′ |
| 机制确证 | `v_front` 消融对照（3.3） | 过速 → 振荡/性能下降，证实约束必要性 |
| 非显然性 | Arm B vs Arm A′ 差距显著 | 仅胜朴素 Arm A 而与 A′ 持平 → 判 No-Go |

> 上表阈值为示意，须在阶段 1.3 据 Arm A′ 实测结果定稿并冻结。

### 4.5 与机器人数据的标定闭环（阶段 5）
机器人实测三维 pH/DO 场用于标定：①各釜 `kLa_i` 空间分布；②OUR 空间剖面；③验证模型预测的锋面位置。须计入 spec §7 注意事项：观测分辨率优于执行分辨率（控制仍受曝气分段粒度限制）；巡测周期与锋面迁移时间相当时，实测为时间平滑近似，标定时作去滞后处理。
