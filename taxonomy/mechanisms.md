# 吸附机制分类体系

## 化学吸附机制

### 配位螯合
- **邻苯二酚配位**：catechol基团与金属离子形成双齿配位键（贻贝、PDA、单宁）
- **氨基螯合**：-NH₂与金属离子配位（壳聚糖、几丁质、藻类）
- **羧基络合**：-COOH与金属离子络合（海藻酸钠、纤维素）
- **巯基结合**：-SH与软金属离子形成极难溶硫化物（SRB）

### 静电吸附
- **正电表面吸附**：带正电表面吸附阴离子（壳聚糖、小球藻）
- **负电表面吸附**：带负电表面吸附阳离子（海藻酸钠、纤维素）

### π-π堆积
- 芳香环与芳香族污染物的π-π相互作用（PDA、单宁、贻贝）

### 氢键
- 表面-OH、-NH等与污染物分子形成氢键（纤维素、壳聚糖）

### 离子交换
- 材料中的可交换离子（Ca²⁺等）被污染物离子替换（牡蛎壳、羟基磷灰石）

## 物理吸附机制

### 孔隙吸附
- **微孔吸附**：<2nm孔径，高比表面积（MOF、活性炭）
- **介孔吸附**：2-50nm孔径，良好传质（硅藻壳）
- **大孔吸附**：>50nm孔径，快速传质（木材、珊瑚）
- **层次孔吸附**：多级孔协同（骨骼、牡蛎壳）

### 表面吸附
- 高比表面积提供的物理吸附位点

## 结构驱动机制

### 超疏水分离
- **Cassie-Baxter效应**：微纳结构+低表面能→超疏水（荷叶、仿荷叶）
- **梯度润湿**：润湿性梯度驱动液滴定向移动（仙人掌刺）

### 超滑表面（SLIPS）
- 液体润滑层使液滴/微生物无法附着（猪笼草）

### 分子筛分
- 精确孔径选择性过滤（离子通道、MOF）

### 网络过滤
- 纤维/根系网络的物理截留（菌丝体、红树林根系）

## 生物过程机制

### 生物矿化
- 生物调控无机矿物的形成（牡蛎壳、珊瑚、铁细菌）

### 生物沉淀
- 微生物代谢产物与金属离子形成沉淀（SRB的硫化物沉淀）

### 生物积累
- 微生物主动摄取和富集金属离子（微藻、细菌）

## 与 feature-mapping.json 的对应关系

本文件按**科学机理**分类（为什么能吸附），feature-mapping.json 按**材料性质**分类（材料有什么特征）。两者是不同维度，通过 `mechanism_feature_bridge` 关联。

| 机理分类（本文件） | 材料性质分类（feature-mapping.json） |
|-------------------|--------------------------------------|
| 配位螯合 | 邻苯二酚基团、氨基、羧基、巯基、金属配位能力 |
| 静电吸附 | 正电表面、负电表面 |
| π-π堆积 | π电子体系 |
| 离子交换 | 离子交换能力 |
| 微孔/介孔/大孔/层次孔吸附 | 微孔、介孔、大孔、层次孔 |
| 超疏水分离 | 疏水性、乳突阵列 |
| 分子筛分 | 分子筛分 |
| 网络过滤 | 网状、纤维状 |
| 生物矿化 | 生物矿化模板 |
| 催化降解 | 活性氧位点、催化降解 |

Agent 在做匹配时，先通过材料性质检索原型，再通过此对应关系解释科学机理。
